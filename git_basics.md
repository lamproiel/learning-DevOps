# Git Basics

## git init
- Инициализирует новый репозиторий
- Создаёт скрытую папку .git

## git add
- Добавляет файлы в staging area
- Синтаксис: git add <file>

# редактирование файла (конспекта)
## nano git_basics.md
- открыть файл в нано
## git status
- проверить статус
## git add git_basics.md
## git commit -m "Update git basics notes"
- закоммитить изменения
## git log 
- посмотреть историю
